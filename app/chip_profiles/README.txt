# 芯片包目录（chip profiles）

本目录存放 DAP RTT 页的「芯片 / 内核」预设。每个文件为一个芯片包，UI 下拉框
会自动扫描并列出，也可用右侧刷新按钮重载，无需改代码。

## 添加方法

1. 复制任意一个 `*.json` 为例，按下方格式新建文件（文件名任意，如 `GD32F303.json`）；
2. 点 DAP 页「芯片 / 内核」右侧的刷新按钮即可出现。

## JSON 格式

> 注意：JSON 不支持十六进制字面量，地址一律写十进制（如 0x20000000 = 536870912）。

```json
{
  "name": "GD32F303 (Cortex-M4)",        // 必填：下拉框显示名
  "kernel": "m4",                        // 必填：内核 key
  "ram_regions": [[536870912, 537001984]],  // 可选：RTT 控制块扫描区间（自动模式使用）
  "swd_speed_khz": 4000,                 // 可选：默认 SWD 速度（kHz）
  "cb_addr": 0,                          // 可选：固定 RTT 控制块地址（0=自动检测）
  "desc": "96KB SRAM @ 0x20000000"       // 可选：悬停提示说明
}
```

### kernel 可用值

| key  | 含义                   |
|------|------------------------|
| auto | 自动（向量表 0x20 → 默认 RAM 区间扫描） |
| m0   | Cortex-M0 / M0+        |
| m3   | Cortex-M3              |
| m4   | Cortex-M4              |
| m7   | Cortex-M7              |
| m23  | Cortex-M23             |
| m33  | Cortex-M33             |
| a7   | Cortex-A7（无通用 RAM 布局，须手动指定地址/区间） |
| a53  | Cortex-A53（同上）     |

### 行为说明

- 选中芯片包后：SWD 速度自动填为 `swd_speed_khz`（若你手动改过速度则尊重你的值）；
  若带 `cb_addr` 会自动切到「固定地址」模式并填入；自动模式下按 `ram_regions` 扫描。
- `ram_regions` 格式为 `[起始地址, 结束地址)`（左闭右开），可写多个区间。
- 格式错误的文件会被自动跳过，不影响其它芯片包。
